# Бэклог проекта react demo

Эта папка содержит бэклог проекта — организованный список задач для улучшения сайта.

## 📁 Структура

```
backlog/
├── README.md           # Этот файл — руководство по работе с бэклогом
├── todo/               # Задачи, ожидающие выполнения
├── inprogress/         # Активно выполняемые задачи
├── done/               # Завершённые задачи (архив)
└── docs/               # Документация и общие планы (вне папок todo/inprogress/done)
```

## 📋 Формат тикетов

Каждый тикет — это отдельный `.md` файл в папке `todo/` с следующей структурой:

```markdown
# [Номер] Название задачи

**Приоритет:** P0 | P1 | P2 | P3
**Оценка времени:** X часов
**Влияние на UI:** Нет / Минимальное / Требует дизайна

## Описание
Краткое описание задачи и зачем она нужна.

## Файлы для изменения
- `путь/к/файлу.ts`
- `путь/к/компоненту.tsx`

## Чеклист
- [ ] Шаг 1
- [ ] Шаг 2
- [ ] Шаг 3

## Время на реализацию
- Общая оценка: X часов
- Разбивка по шагам (если нужно)

## Валидация
Как проверить, что задача выполнена:
1. Проверка 1
2. Проверка 2

## Зависимости
От каких задач зависит эта (если есть).
```

## 🔄 Процесс работы

### 1. Выбор задачи
- Откройте папку `todo/`
- Выберите задачу с наивысшим приоритетом (P0 > P1 > P2 > P3)
- Прочитайте описание и чеклист

### 2. Начало работы
- Переместите файл тикета из `todo/` в `inprogress/`
- Начните выполнение по чеклисту

### 3. Завершение
- Выполните все пункты чеклиста
- Пройдите валидацию
- Переместите файл тикета из `inprogress/` в `done/`

## 🏷️ Приоритеты

| Приоритет | Описание | Срок |
|-----------|----------|------|
| **P0** | Критическое — блокирует другие задачи или влияет на SEO | 1-2 дня |
| **P1** | Важное — существенно улучшает метрики | 1 неделя |
| **P2** | Улучшения — оптимизация и доработки | 2 недели |
| **P3** | Долгосрочное — планируется на будущее | 1+ месяц |

## 📊 Отслеживание прогресса

Для просмотра статуса бэклога:

```bash
# Посчитать задачи в каждой папке
echo "Todo: $(ls -1 backlog/todo/*.md 2>/dev/null | wc -l)"
echo "In Progress: $(ls -1 backlog/inprogress/*.md 2>/dev/null | wc -l)"
echo "Done: $(ls -1 backlog/done/*.md 2>/dev/null | wc -l)"
```

## 📝 Документация

Общие документы и планы хранятся в папке `docs/`:
- `SEO-AUDIT-TASKS-SUMMARY.md` — сводка задач по SEO аудиту от марта 2026

## 💡 Советы

1. **Не берите больше 1-2 задач одновременно** — фокус на качестве
2. **Сначала P0** — критические задачи всегда в приоритете
3. **Обновляйте статус** — перемещайте тикеты сразу при изменении статуса
4. **Архивируйте done** — раз в месяц можно удалять старые выполненные задачи
