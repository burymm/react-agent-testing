# Pages & Routing

## Root Layout — `app/layout.tsx`

```tsx
export const metadata = {
  title: "Next Demo",
  description: "Generated by create next app",
};

export default function RootLayout({ children }) {
  return (
    <html lang="ru" className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}>
      <body className="min-h-full flex flex-col">
        <Navbar />
        {children}
      </body>
    </html>
  );
}
```

- Подключает шрифты Geist Sans + Geist Mono через `next/font/google`
- Обёртывает все страницы в flexbox-раскладку с Navbar сверху
- `lang="ru"` — атрибут языка HTML

## Home — `app/page.tsx`

**Route:** `/`

Стандартная стартовая страница create-next-app:
- Логотип Next.js (`/next.svg`)
- Заголовок с призывом к редактированию `page.tsx`
- Ссылки на Templates и Learning center
- Кнопки "Deploy Now" (Vercel) и "Documentation"

## Posts listing — `app/posts/page.tsx`

**Route:** `/posts`
**Type:** Server Component (async)

```tsx
export default async function PostsPage() {
  const posts = await getAllPosts();  // from lib/api.ts
  // renders card for each post with title, text, and "Details" link
}
```

- Асинхронно загружает все посты через `lib/api.ts`
- Рендерит карточки с бордером в flex-контейнере
- Каждая карточка содержит: заголовок, текст, ссылка "Details" → `/post/:id`

## Post detail — `app/post/[id]/page.tsx`

**Route:** `/post/:id`
**Type:** Server Component (async)

```tsx
export default async function PostPage({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;  // Next.js 16: params is a Promise
  const post = await getPostById(id);
  if (!post) return <NotFound />;
  // renders title, date, text
}
```

- Использует `await params` — новый паттерн Next.js 16
- Загружает пост через `lib/api.ts`
- При отсутствии поста рендерит `NotFound` компонент напрямую (не через `notFound()` function)

## Not Found — `app/post/[id]/not-found.tsx`

**Route:** scoped to `/post/[id]`

```tsx
export default function NotFound() {
  return (
    <div className="flex flex-1 flex-col items-center justify-center gap-6 px-16 py-32">
      <h1 className="text-5xl font-bold">404</h1>
      <p className="text-xl text-zinc-600 dark:text-zinc-400">Post not found</p>
      <Link href="/posts" className="...">Back to posts</Link>
    </div>
  );
}
```

- Отображается только при запросе несуществующего поста
- Содержит ссылку возврата на `/posts`
